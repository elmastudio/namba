# Namba

Namba is a Premium blog and magazine theme with a minimal, fresh, responsive web design and flexible, easy-to-use features. The post format filters and color options are a special theme highlight to make your blog more fun and exciting to read and the Namba widget options offer lots of interesting ways to feature your blog content.

By [Elmastudio](https://www.elmastudio.de/en/).

- **Version:** 1.1.8
- **Theme page:** https://www.elmastudio.de/en/themes/namba/
- **Documentation:** [English](https://www.elmastudio.de/en/docs/namba/) / [German](https://www.elmastudio.de/doks/namba/)

## Installation

Download this repository as a ZIP and upload it in **Appearance → Themes → Add New → Upload Theme**, or clone it into your WordPress installation:

```
cd wp-content/themes
git clone https://github.com/elmastudio/namba.git
```

## Updates

Install the Git Updater plugin (https://git-updater.com/) and WordPress will offer new versions of this theme as regular theme updates, straight from GitHub.

## Status

This theme is no longer actively developed. It is published here as-is, for anyone who still runs it or wants to build on it.
